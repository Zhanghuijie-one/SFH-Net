# Dataset directory

The datasets are not redistributed in this repository. Download LOL-v1 from its official source and place the paired images in the following directories:

```text
data/
`-- LOLv1/
    |-- Train/
    |   |-- input/
    |   `-- target/
    `-- Test/
        |-- input/
        `-- target/
```

Input and target images must be paired and have matching filenames after lexicographic sorting.
